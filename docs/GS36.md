# GS36 — 2026-11-10: the game stopped in Venus Lighthouse (light reaching an empty socket)

User (phone, retrowser): "I got an error in the Venus lighthouse" — RuntimeError out of bounds in
VenusLighthouse_RouteLight, from JumpOrPushSocketPillar.

## Cause
VenusLighthouse_RouteLight (scene/venus_lighthouse.c) looks up the pillar on the socket a light reached. A socket can be
empty (vendor comment: one third-floor solution leaves the south-east one empty); the original then reads through
address 0 into the BIOS, fails the spiral-pillar test and the light goes out (gVenusLightGoesOut). In wasm address 0 is
our own memory: the reads went out of bounds and stopped the game (trap 98).

## Fix
port/c_rules.tsv: after `Actor_FindAtPosition`, no pillar -> `Actor_StartScript(light, gVenusLightGoesOut); return 0;`.

  STOPPED: memory access out of bounds"; after: returned, the light's script started, the game runs on (f3600 picture).
