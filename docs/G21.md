  gElement_PowerResistCurve in the ROM is (200,256) (100,128) (0,0) (-100,-128) (-200,-256), as the source says.
- **Our damage to Tret** (attack: ((Atk - Def) * 256 >> 9) + 0..3; a critical adds 1/4 and Lv/5 + 6 before the roll):
  Isaac Atk 63 -> 18-21, seen 18, 19, 21 (critical 30-33, seen 32); Garet Atk 60 -> 16-19, seen 17, 19; Ivan Atk 37 -> 5-8,
  seen 5, 7, 8 (critical 14-17, seen 14). Psynergy (power * multiplier(power - resistance) >> 8, + 0..3): Ivan's Ray 35 at
  Jupiter 104 vs 100 -> 35-38, seen 36, 37, 38; Garet's **Volcano** 45 at Mars 109 vs **25** (x1.42) -> 63-66, seen 63, 65,
  66; Isaac's Spire 40 at Venus 104 vs 72 -> 46-49, seen 47; Venus summon (30 + 3% of 710 = 51, x1.16) -> 58-61, seen 60.
- **Tret's damage to us**: attack on Isaac (Def 29) -> 30-33, seen 31; on Garet (Def 31) -> 29-32, seen 32. Quake (power 12,

## 5. Checked, no port bug found

0 distinct stubs hit on every route. No asm/C change: no EQUIV spec, the wasm was not rebuilt.

- **Tret's damage numbers**: all match the vendor formulas and the ROM tables (section 1).
- **Silence for 3 s after the battle** (tret_win audio, windows 317-319): TreeRooms_PlayPostBattleConversation plays
  SOUND_FADE_OUT_BGM, the backdrop fade and the camera move before SE_MAP_EXIT and MUS_FOREST. Game behaviour.
- **Isaac's HP rose 91 -> 98 on turn 1**: the Djinn command set Flint (on standby since GS19's unleash), a class change.
- **Kolima Forest's tree scene in dark green** after the battle: the cursed palette set (KolimaPalette_Curse) stays until
  Hermes' Water; G19's frames of the scene have the same colours.
- **The World Map's walls are not cells**: hpath finds no path there (it reads map cells). WorldMap_GetCollision (terrain.c)
  reads 4-bit collision pixels from two 64 x 64 tile maps in screen blocks 8 and 10; our reading matches the game's own
  function at the leader (port_work/g21/wmchk.cjs calls it read-only through Port_CallCode4). Rivers can be 10 px wide.
- **Walking east from Kolima Forest's World Map exit re-enters the forest**: its area actor (447,65) is touched; the way on
  is south. Game behaviour.
- **Bilibin Cave's corridors**: walls are 16-px outlines (MAP_MODE=height), the void outside is height 0 too, so hpath's
  model reaches everywhere; walk by the height map and screenshots.
