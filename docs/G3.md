## Test interpreter and differential harness (D20)

`tests/arm/arm7.js`: ARMv4T, ARM and Thumb, flat memory = the game module's linear memory (identity map);
accesses outside the GBA regions and its own stack at 0x0D000000 throw, as do coprocessor, SWP, user-bank and
mode-changing instructions. Coverage used so far: every ARM data-processing op with all shifter forms, MUL/MLA,
UMULL/SMULL/SMLAL, LDR/STR (imm/reg, pre/post, writeback, unaligned rotate), LDRH/STRH/LDRSB/LDRSH, LDM/STM
all modes, B/BL/BX, SWI, MRS/MSR (flags); all 19 Thumb formats except SWI-free edge cases.

`tests/arm/diff.cjs`: per routine, random + edge inputs (and the ROM's real data: all 1000 resource
directory entries for the decoders, real messages, the ROM's icons); original runs first, memory is restored,
then the C port; result register and all of EWRAM/IWRAM/IO/palette/VRAM/OAM/flash compared.
`tests/arm/selftest.cjs`: negative controls (mismatched pairs must differ).

**39/39 routines EQUIV**: IwramSignedDivide/Remainder, IwramUnsignedDivide/Remainder, __divsi3,
IwramRatioMulQ14, IwramMulQ16, IwramSqrt, Iwram_SqrtFarArm, Iwram_RatioMulQ14FarArm, Trig_Sin, Trig_Cos,
umul3232H32, ArcTan2FarArm (vendor C ArcTan2 in wasm vs the ROM's), IwramFillWords, IwramClearWords,
IwramCopyWords, IwramExpandBitRuns, IwramTransformVector, IwramTransformMatrix, IwramDecompress, Heap_Release,
HeapSlot_Release, Bios_CpuSet, Bios_SoundBiasOn/Off, SoundMainBTM, RealClearChain, Oam_BuildBufferKernel,
Message_FindArm, Text_DecodeSymbol, Decompress_TaggedLzArm, Decompress_MoveToFrontLzCommands,
Resource_PatchThumbBranch, Tile_ConvertMapGrid, Resource_ExecuteTransfer, Tile_Decompress4bpp,
Tile_ExpandOpaque, Tile_ExpandMasked.

Non-C semantics kept: signed remainder takes the sign of dividend XOR divisor; division by zero gives an
all-ones quotient and the dividend as remainder; fill/copy words write size & ~3 bytes through an unrolled
shape; IwramDecompress's back references copy from the *source* stream, bytes above 223 skip output;
Resource_PatchThumbBranch scans twice the code size (past the overlay); the tile packers let high nibbles
bleed as the ARM does.

BIOS: the game calls only Halt, Stop, CpuSet, SoundBias and SoundGetJumpList (no Div/Sqrt/ArcTan/LZ77/RL/
Huffman/affine SWIs anywhere in the vendor code), so only CpuSet and SoundBias are in C (`port/pc/bios.c`),
tested against an independent GBATEK reference in the harness. SoundGetJumpList needs the BIOS's own table:
not needed while audio is silent.

## How the boot works

- **Calls by GBA address** (`port/pc/codemap.c`): bind.py rewrites every indirect call in the IR through
  `Port_ResolveCode`; table indices pass, GBA addresses are looked up in: aliases (registered when an immediate
  DMA copies from a function start: RamCode_Load copies of ARM routines, the stack copy in
  IoWriteQueue_FlushPending; any data written over removes them), the loaded overlay's functions, the main
  image's functions (`build/wasm/gen/code_map.ll`: every code symbol whose name is a wasm function; our ports
  keep the original names). Unknown address: printed and abort, which names the next routine to port.
- **Overlays (D7)**: Decompress_TaggedLzArm, decoding a scene overlay's resource into gOverlayArea, switches
  the code map to that overlay and fills its relocated tables. The overlay's entry table pointers
  (`gOverlayArea.initialize()`...) then resolve to `ovNNN_` functions.
- **Frame driver (D8)** `port/pc/hw.c`: time passes only in `Port_BiosHalt` (swi 2 in wait()): per line,
  render (visible lines), HBlank (IRQ, HBlank DMA), next line (VCOUNT match IRQ), line 160: frame complete ->
  `port_frame_ready` (host; the page suspends there with ASYNCIFY), keypad, VBlank IRQ and DMA. Interrupts are
  dispatched like IwramIrqMain (order HBlank, VBlank, VCount, Timer3, Serial, Timer1, Timer2, Keypad, GamePak;
  handlers from gIrqHandlers through Port_ResolveCode). Busy-waits on VCOUNT in vendor C are rewritten at
  build time (`port/c_rules.tsv`) to `Port_ReadVCount`, which advances the display one event.
- **DMA**: immediate on Dma_Set (Port_DmaWritten) or when found enabled at a halt; VBlank/HBlank timing at
  those events with repeat/reload; sound FIFO ignored. **Timers**: prescaler/cascade/overflow IRQ, counters
  internal (the register keeps the reload). **Keys**: `Port_SetKeys(mask)` -> KEYINPUT at VBlank, KEYCNT IRQ.
- **Flash**: replaced at the driver API (`port/fn_overrides.tsv`, `port/pc/flash.c`), SST id, 0xFF blank,
  persisted by the page in IndexedDB.
- **PPU v1** `port/pc/ppu.c`: modes 0-2, text BGs (4/8bpp, flips, sizes), affine BGs (ref points latched at
  VBlank, stepped per line, reloaded on write), sprites (normal/affine/double, 1D/2D, 4/8bpp, semi-transparent,
  OBJ window), windows 0/1/OBJ, alpha/brighten/darken. Not yet: mosaic, bitmap modes 3-5.
- **Page** `port/web`: picker (size + SHA-1), IndexedDB ROM and save, canvas 240x160 (CSS-scaled, pixelated),
  keyboard into one key state (the touch pad will feed the same), 59.73 Hz pacing with rAF.
