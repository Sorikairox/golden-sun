# G6 field notes (session GS6, 2026-11-01): battles run

Session notes for GS6. Battles are a G4 item (single player); the link survey is preparation for G6/G7 and lives in
`docs/LINK.md`. The file name is the session's.

## 1. How a battle is reached (test-only entry)

No scripted route to a real battle exists yet: the prologue's own monster fights (ValePrologue cells with behavior
16/17, `ValePrologue_FightThirdMonster`/`FourthMonster`, zone 12 slots 2/3) are across the river bridge (west, cells
4-5,54) and near the plaza exit (23,85); walking west stops at cell 15,56 behind the tree, so the route there is
still open (G5's routing tools: `tests/probes/mapdump.cjs`, `where.cjs`).

Instead, a **test-only debug entry** that uses the game's own code path:

- `tests/probes/battle.cjs` (node, `tests/boot.cjs --probe`): at frame `BATTLE_AT` (default 5400, free walking in
  ValePrologue after `prologue.keys` + `first_rock.keys`) it reads the formation of zone `BATTLE_ZONE` slot
  `BATTLE_SLOT` (default 12/2, the stormy night's monster) from the ROM's `gEncounterZones` and writes it into
  `gFieldWork->encounter` (offset 380). That is the field `Field_RequestBattleFromEncounterTable` writes. The
  field sequence then does the rest: `Actor_Snapshot`, `SEQUENCE_BATTLE` (scene 510), `Field_StartEncounterTransition`,
  `MainRoutine` -> `Battle_RunFar(3)`, and back to the scene afterwards. Battle music is not chosen
  (`Encounter_SelectBattleMusic` skipped).
- `tests/web_shot.cjs --battle FRAME`: the same write in the page via CDP (`window.__gs.HEAPU8`).

Formation 3 = two Wild Mushrooms against Isaac (Lv 1, HP 30, PP 13).

## 4. Notes

- The divisions: agbcc has no divide instruction, so every `/` and `%` by a variable is a libgcc call; the IwramSigned
  routines give `%` the sign of dividend XOR divisor, unlike C. Before this session the wasm build used C semantics
  for those 412 sites; now they match the ROM. Constant divisors keep clang's code (the same results).
- Blitter alias entries: 8 rotating parameter slots (the game uses 2 slots, HEAP_SLOT_RAM_CODE/_2).
