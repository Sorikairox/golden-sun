Found and fixed:
- **World Map garbage when the party stands still** (ppu.c): the World Map's HBlank DMA rewrites BG2X/Y every line;
  ppu.c reloaded the reference point only when the value changed, so when the camera turned back to face north a line
  repeated the previous value and stepped by BG2PD (garbage in that page). GBA rule: any write reloads. hw.c now
  reports DMA writes to I/O (`Port_PpuIoWritten`). Trap 38.
- **TileMap_DrawRows** (field/picture_decode.s, the still picture when a menu opens on the World Map): aborted at
  Port_ResolveCode; ported to C (field_asm.c), EQUIV 120 cases (random pages incl. pa/pc 0, BG3 fallback), negative
  control fails.
- **Credits_DecodeBackground** (menu/credits_background_decode.s): the battle-background decoder with the pixel offset
  in r2; BitDecoder's C body shared (battle_asm.c), EQUIV 300 cases (offsets 0, 0x80808080, random).

Not hit / left: `Decompress_HalfwordLz` (only the debug palette editor calls it), `FarCall_ResourceTable` (only the
debug sprite viewer); `FarCall_RuntimeTable` is used by Transform_UpdateVertices on the World Map (atan2/sin/cos
targets resolved through Port_ResolveCode: it ran without an abort). The credits as the game plays them (Credits_Run,
the ending) were not reached. 0 distinct stubs hit in every run; 1 logged stub as before (`_call_via_r0`, dead).

## 3. Regression script

`tools/regress.sh` (private copy of build/wasm in port_work/regress/bin; ~32 s):

```
tools/regress.sh                 # all cases: OK/DIFF per case, exit 1 on any DIFF or stop
tools/regress.sh worldmap link2  # some cases
tools/regress.sh --update        # rewrite tests/regress/expected.tsv (only after a change meant to alter results)
```

Cases: prologue_save (digest + SHA-1 of the saved flash; the save is byte-identical to GS4's), garet, boulder (real
play), battle_fight, battle_party, battle_summon, battle_lost, field_psynergy, worldmap, credits (test-only probes),
link2 (tools/link2.sh: 20/20 agree, its two RAM digests). Each node case prints `digest fN ram R pic P`
(tests/probes/digest.cjs: SHA-1 of EWRAM, IWRAM, palette, VRAM, OAM and of the frame picture, 16 hex digits).
Expected values are digests only. Two runs gave identical digests (deterministic). A digest DIFF means "look":
compare captures of that case (the logs are in port_work/regress/).
