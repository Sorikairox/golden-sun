Golden Sun

A source port of the Game Boy Advance game for the browser. It needs your own copy of the cartridge: choose the ROM file (Golden Sun, USA/Europe). It stays on this device.

Keys: arrows = D-pad, X = A, Z = B, Enter = Start, Backspace = Select, A = L, S = R
In the game: START, then R opens these picture settings too.
Link battle online Two players, each with their own cartridge and a save with a Djinn found, meet in the Battle Arena (File Screen > Battle). One hosts, the other joins with the room code. Direct connection only (no relay server): some networks cannot connect.
You are offline: online play needs an internet connection. The game itself works offline.
